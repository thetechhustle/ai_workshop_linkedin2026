# AGENTS.md

## Project context

This is a student learning project. Prioritize readability, small safe changes, and explanation.

## Setup commands

- Install dependencies: `make install`
- Serve workshop docs: `make run`
- Run example app: `make startapp`
- Run tests: `make test`
- Run lint: `make lint`

## Workflow

1. Explain before editing.
2. Propose the smallest safe plan.
3. Show what files will change.
4. Run tests after edits.
5. Summarize the diff.

## Boundaries

- Do not commit private keys or tokens.
- Do not delete files unless asked.
- Do not introduce new frameworks without approval.
