# Production Awareness Checklist

A project is stronger when it can be run, tested, reviewed, and explained.

Before sharing an app widely, check:

- Environment variables are documented.
- Data storage is understood.
- Tests run in CI.
- Errors are handled clearly.
- Dependencies are tracked.
- There is a rollback plan.
- Someone knows who owns the service.

Beginner version:

> Can people depend on this, and do we know what to do when it fails?
