# Videos and Official Docs

Use videos as warmups, not replacements for building. The best pattern is: watch a short explanation, run one command, then write one sentence in your own words.

## How to use this page

For each topic:

1. Watch or skim for 3-5 minutes.
2. Write one sentence: “This matters because...”
3. Run the related command or lab step.
4. Ask one question if it still feels fuzzy.
