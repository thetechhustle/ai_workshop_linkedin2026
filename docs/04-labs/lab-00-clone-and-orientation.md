# Lab 00 — Clone and Orientation

## Goal

Get the repo on your laptop, install dependencies, and prove your setup works.

## Commands

```bash
git clone https://github.com/thetechhustle/ai_workshop_linkedin2026.git
cd ai_workshop_linkedin2026
make install
make test
make run
```

## Verify

You should see tests pass.

```text
4 passed
```

`make run` should start the workshop book at <http://127.0.0.1:8001>.

When the instructor asks you to run the example app:

```bash
make startapp
```

Open <http://127.0.0.1:8000/docs>.
