# LinkedIn AI Workshop 2026

<div class="bd-callout">
<strong>Workshop thesis:</strong> AI coding agents can help students build faster, but the real skill is learning how to guide, verify, and improve what AI produces.
</div>

Welcome to the workshop home base. This site is designed to feel like a book you can move through during class and return to after class.

## What you will do today

1. Clone this repository.
2. Run a real app locally.
3. Use the terminal without fear.
4. Learn the difference between copilots and agents.
5. Ask AI to inspect a codebase.
6. Make one small safe change.
7. Verify your work with tests or a review checklist.
8. Leave with a next-step plan.

## Student promise

By the end of the workshop, you will be able to say:

> I did not just ask AI to write code. I understood the system, made a controlled change, verified it, and can explain what happened.
