Welcome to the workshop home base. Treat this site like your class notebook, lab manual, and command center. You do not need to already feel like an engineer to use it. The goal is to help you build confidence one small verified step at a time.

## Why this workshop exists

A lot of students are being told that AI will either replace them or magically make them engineers overnight. Both ideas are wrong. AI can help you move faster, but it does not remove the need to understand code, ask clear questions, read errors, test changes, and make responsible decisions.

Today you will practice the habits real engineering teams care about:

- opening a project,
- running it locally,
- asking AI for help without giving up your judgment,
- using Git to track a small change,
- running a quality gate,
- explaining what changed and why it matters.

## The student path

| Step | What you do | What you learn |
|---|---|---|
| 1 | Clone the repo and open the workshop book. | A repo can be more than code. It can be a learning environment. |
| 2 | Run the setup and tests. | Good projects give you a way to prove your machine is ready. |
| 3 | Start the example app. | Localhost, ports, APIs, and databases become concrete. |
| 4 | Ask AI to inspect the project. | AI is useful when you give it context and verify the answer. |
| 5 | Make one small change. | Engineering progress is controlled, reviewed, and reversible. |
| 6 | Run a quality gate. | A change is not done until you have evidence. |
| 7 | Share your next step. | Communication is part of the job. |

## What you will be able to say by the end

> I did not just ask AI to write code. I understood the project, made a controlled change, verified it, and can explain what happened.

## How to move through this book

Start with [Start Here](00-start-here.md), then follow the labs in order. If you are new, stay on the Bronze path. If you already have experience, use the Silver or Gold stretch challenges.

- **Bronze:** I can run the workshop book, run the app, and explain what I see.
- **Silver:** I can make one small change and verify it.
- **Gold:** I can add a stronger quality gate, improve documentation, or explain a production-readiness concern.
