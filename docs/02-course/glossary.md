# Student-Friendly Engineering Glossary

| Term | Beginner explanation |
|---|---|
| AI co-pilot | A tool that helps you think, code, debug, or explain. You still drive. |
| Agent | AI that can plan steps, use tools, take actions, and report back. |
| Terminal | A text interface for running commands. |
| tmux | A terminal cockpit that lets you keep multiple panes open. |
| Git | Version control. It tracks changes over time. |
| Branch | A safe workspace for changes before they merge. |
| Diff | The exact lines that changed. |
| Commit | A saved checkpoint with a message. |
| Pull request | A proposed change for review. |
| Localhost | Your own computer, usually reached at `127.0.0.1`. |
| Port | A numbered door where a service listens, like `8000`. |
| API | A way for software to talk to software. |
| Database | A place where an app stores data. |
| SQLite | A lightweight database stored in a local file. |
| Container | A packaged app environment that runs consistently. |
| CI/CD | Automation that checks, builds, tests, and sometimes deploys code. |
| Quality gate | A test, lint check, review, or checklist that protects the project. |
| Production | The real environment users depend on. |
