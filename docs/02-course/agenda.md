# 4-Hour Workshop Agenda

| Time | Segment | Focus |
|---:|---|---|
| 0:00-0:15 | Opening | AI as a learning accelerator. |
| 0:15-0:35 | Clone repo | Students run setup checks and see the app. |
| 0:35-0:55 | tmux cockpit | App, tests, Git, and AI prompts in panes. |
| 0:55-1:20 | Git workflow | Branches, commits, diffs, review habits. |
| 1:20-1:45 | AI workflow demo | Prompts, planning, review, and verification. |
| 1:45-2:00 | Break | Reset and debug. |
| 2:00-2:35 | Project triage | Inspect structure and identify improvements. |
| 2:35-3:10 | Build lab | Add a feature, fix a bug, refactor, or improve docs. |
| 3:10-3:35 | Quality gates | Tests, style checks, and review habits. |
| 3:35-3:50 | Production awareness | Containers, databases, localhost, ports, HTTPS, CI/CD. |
| 3:50-4:00 | Showcase | Share what changed, what was verified, and what comes next. |

## Instructor note

Protect student confidence. The win is not covering every concept. The win is that every student leaves with a controlled next step.
