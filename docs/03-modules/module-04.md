# Module 04 — Production Readiness

## Concept

A project is stronger when it can be run, tested, reviewed, and explained.

## Vocabulary

- `localhost` means your own machine.
- A port is where a service listens.
- SQLite is a small local database.
- Docker packages an app with its dependencies.
- CI runs checks in GitHub before changes merge.

## Checkpoint

You can explain why “it works on my laptop” is only the beginning.
