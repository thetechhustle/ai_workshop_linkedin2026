# Module 03 — AI Copilots and Agents

## Concept

A co-pilot helps answer or explain. An agent can plan steps, use tools, and report back. The student still owns the final decision.

## Agent roles

| Role | Job |
|---|---|
| Planner | Propose the smallest safe plan. |
| Builder | Make a focused change. |
| Tester | Create or run a quality gate. |
| Reviewer | Inspect the diff and risks. |
| Ship Captain | Decide what must be true before release. |

## Checkpoint

You can assign a task to the right role instead of asking one giant prompt to do everything.
