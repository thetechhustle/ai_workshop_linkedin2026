# Instructor Run of Show

## Before students arrive

- Open the slide notes.
- Clone repo fresh.
- Run `make test`.
- Run `make run` and open the workshop book.
- Run `make startapp` when you need the local API.
- Open the local API docs.
- Confirm room Wi-Fi and projection.

## Live flow

1. Start with the workshop message.
2. Move students into the repo quickly.
3. Use `make help` as the anchor.
4. Show tmux as the cockpit.
5. Build from the starter app unless students have working projects ready.
6. Keep the loop visible: Understand, Plan, Build, Verify, Ship Mindfully.

## Close

Ask every student:

- What did you change or understand?
- How did you verify it?
- What is your next step?
